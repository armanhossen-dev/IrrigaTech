IrrigaTech

Smart Irrigation. Effortless Farming.

Companion app for the EcoSense ESP32-S3 irrigation rig.

Material 3 Flutter app with Riverpod, go_router, Demo + live Blynk REST, Google Sign-In, motor interlocks, EcoSense-format alerts, and Hive history. Default first run is fully demoable without hardware.

  • Dashboard, motors, analytics, alerts, security log, settings
  • Rain lock on Motor 1 · tank-full lock on Motor 2
  • Package com.ahrn.irrigatech

Built by Arman Hossen (AHRN). Unzip, then flutter pub get && flutter run.
